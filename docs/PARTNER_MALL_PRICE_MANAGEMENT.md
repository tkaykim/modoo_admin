# 파트너몰 판매가 설정

## 범위와 기획

최근 생성한 `buddumak` 몰의 현존 상품을 각각 11,900원으로 설정한다.
최초 조회에서는 2개였지만 작업 중 재조회에서 1개가 삭제된 것을 확인했으며, 삭제된 상품을 복구하지 않는다.
같은 이름의 기존 박람회 몰 `expo84-4624`는 이번 변경 대상이 아니다.

가격 입력이 전체 면 편집기에만 있어 놓치기 쉬웠으므로 진열 초안에도 판매가 입력창을 둔다.
신규 몰과 상품 추가의 최종 저장 전에는 모든 상품의 판매가 입력을 확인한다.
등록 후에는 상품 카드에 항상 보이는 `가격 수정`에서 디자인을 열지 않고 가격만 변경한다.
0원 이상의 정수를 허용하며, 기존 주문·원본 디자인·캔버스·인쇄 배치는 변경하지 않는다.
가격은 인쇄비를 포함한 상품 단가이며 몰 할인·쿠폰은 기존 정책에 따라 별도로 적용된다.

## 구현과 검증

- 생성: 전체 면 편집기 또는 진열 목록에서 판매가를 입력한다.
- 수정: 파트너몰 상세의 각 상품 카드에서 `가격 수정`을 누른다.
- 저장: 기존 관리자 인증 API에 상품 ID와 가격만 PATCH한다.
- 검증: 누락·음수·소수 가격, 생성·추가 시 판매가, 가격 수정 취소·실패·재시도·재조회, 디자인 비변경, 고객 표시가와 주문서 단가를 확인한다.
- 화면: 기존 관리자 모달·테두리·버튼을 따르며 PC와 모바일에서 확인한다.
- 정리: 새 운영 검증 몰은 E2E 종료 시 정확한 생성 ID로 삭제한다.
  이전 작업의 검증 몰도 주문·장바구니·리드 연결이 없는 것을 확인한 뒤 삭제한다.

스키마 변경과 고객앱 코드 변경은 없다.
결과 증거는 `e2e/artifacts/partner-mall/`에 저장한다.
