# 네이버 스마트스토어 운영 연동

## 필요한 환경변수

- `NAVER_COMMERCE_CLIENT_ID`: 네이버 커머스 API 센터 애플리케이션 ID.
- `NAVER_COMMERCE_CLIENT_SECRET`: 네이버 커머스 API 센터 애플리케이션 시크릿.
- `NAVER_COMMERCE_PROXY_URL`: 선택값이며, 비어 있으면 기존 `LOGEN_PROXY_URL`을 사용한다.
- `NAVER_COMMERCE_PRODUCT_TEMPLATE_NO`: 읽기 전용 연동 테스트와 기본 템플릿 확인용 원상품 번호다.

네이버 API 센터의 API 호출 IP에는 Oracle 프록시 공인 IP가 등록되어 있어야 한다.

## 운영 화면

관리자 사이드바의 `네이버 스마트스토어`에서 다음 기능을 사용한다.

1. 자체몰 상품을 기존 네이버 상품의 배송·고시정보 템플릿으로 신규 등록한다.
2. 네이버 상품의 상품명, 판매가, 재고를 수정한다.
3. 주문 변경분을 동기화하고 발주 확인한다.
4. 같은 네이버 주문번호의 상품주문을 묶어 로젠에 접수한다.
5. 로젠 출력 후 송장번호를 가져와 네이버 발송처리한다.
6. 일별 정산과 상품 문의를 동기화하고 문의에 답변한다.

네이버 주문은 원상품 번호와 채널상품 번호로 `naver_product_mappings`를 조회해 자체몰 `products.id`와 연결한다.

선택한 색상·사이즈·인쇄 크기의 판매자 관리 코드는 `option_manage_code`에 함께 저장한다.

## 안전장치

- 스마트스토어 상태를 바꾸는 버튼은 관리자 인증을 통과한 서버 라우트에서만 호출한다.
- 상품 등록·수정과 문의 답변은 브라우저 확인창을 한 번 더 거친다.
- 임시·테스트 상품은 신규 등록 후 원상품과 채널상품을 모두 `SUSPENSION`으로 재확인해 판매와 노출을 막는다.
- 자체몰 이미지의 `image/jpg`는 네이버가 받는 `image/jpeg`로 정규화하고 JPEG·PNG·GIF·BMP만 업로드한다.
- 로젠 접수 전 `fixTakeNo=NV-{네이버 주문번호}`를 조회해 중복 접수를 막는다.
- 로젠 조회 실패 시 접수를 진행하지 않는 fail-closed 방식이다.
- 새 네이버 테이블은 RLS를 활성화하고 `anon`과 `authenticated` 권한을 회수했다.
- 네이버 공식 커머스 API에는 구매 리뷰 본문 조회 API가 없어 리뷰 자동 통합은 지원하지 않는다.

## 읽기 전용 연동 확인

```powershell
npm run test:naver-commerce
```

이 검사는 상품, 주문 변경분, 정산, 상품 문의를 조회하고 내부 네이버 원장에 멱등 upsert한다.

상품 생성, 발주 확인, 로젠 접수, 네이버 발송처리, 문의 답변은 실행하지 않는다.

## 실제 쓰기 카나리

- 2026-08-24 자체몰 상품 `00085-CVT`를 사용해 테스트 상품 1개를 실제 등록했다.
- 생성된 네이버 원상품 번호는 `13672131679`이고 채널상품 번호는 `13732652927`이다.
- 원상품 판매 상태와 채널 노출 상태가 모두 `SUSPENSION`이고 네이버쇼핑 등록은 `false`임을 상품 상세 재조회로 확인했다.
- 테스트 후 전체 상품 26개를 내부 원장에 다시 동기화했다.
- 동일 주문 변경분 조회는 성공했고 조회 구간의 실제 주문 변경분은 0건이었다.

## 1차 판매 상품 등록

2026-08-24 아래 상품 3개를 네이버에 실제 등록하고 판매·노출 상태를 `SUSPENSION`으로 재확인했다.

| 자체몰 상품 | 네이버 원상품 / 채널상품 | 기본 판매가 | 옵션 구성 | 조합 수 |
| --- | --- | ---: | --- | ---: |
| `00085-CVT` 베이직 라운드 티셔츠 | `13672223064` / `13732745532` | 11,900원 | 색상 11 × 사이즈 14 × 인쇄 3 | 462 |
| `00113-BCV` 오버핏 라운드 티셔츠 | `13672223161` / `13732745608` | 13,900원 | 색상 8 × 사이즈 4 × 인쇄 3 | 96 |
| `00216-MLH` 쮸리 후드티 | `13672223257` / `13732745720` | 25,500원 | 색상 7 × 사이즈 12 × 인쇄 3 | 252 |

기본 판매가는 의류 가격과 소형 DTF 인쇄비 4,000원을 합한 값이다.

인쇄 옵션은 소형 0원, 중형 2,000원, 대형 4,000원 추가로 설정해 실제 DTF 인쇄비 4,000원·6,000원·8,000원에 맞췄다.

113-BCV 대표 이미지는 자체몰에서 사용 중인 Printstar 착용·상품 이미지로 교체하고 흰색 단품 이미지를 추가 이미지로 등록했다.

등록 스크립트는 `NAVER_INITIAL_PRODUCTS_CONFIRM=REGISTER_THREE_SUSPENDED_PRODUCTS` 확인값이 있어야 실행되며, 기존 매핑이 있으면 중복 생성하지 않는다.

전체 네이버 상품 29개를 원장에 다시 동기화했고 상품 상세 읽기, 옵션 수, 판매중지, 네이버쇼핑 미등록 상태를 확인했다.

운영 DB에는 `naver_product_orders.local_product_id`와 `option_manage_code`를 추가했다.

실제 결제 주문이 없어 주문 수집 후 자체몰 상품 연결까지의 실주문 E2E는 아직 실행하지 못했다.

Production 배포가 완료되면 관리자 화면과 매시 15분 정기 주문 수집이 활성화된다.

첫 실주문, 취소, 환불, 발송 처리는 실제 주문으로 각각 검증하고 결과를 운영 기록에 남긴다.
