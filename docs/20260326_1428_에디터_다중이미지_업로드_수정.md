# 에디터 다중 이미지 업로드 수정

**수정일**: 2026-03-26 14:28  
**수정 파일**: `components/canvas/Toolbar.tsx`

---

## 문제 현상

사용자가 이미지를 여러 개 첨부했지만, 에디터 캔버스에는 첨부파일이 하나만 추가되는 현상 발생.

## 원인 분석

`addImage` 함수에서 파일 선택 input 요소 생성 시 두 가지 문제가 있었음:

1. **`multiple` 속성 누락**: `<input type="file">` 요소에 `multiple` 속성이 설정되지 않아, 파일 선택 다이얼로그에서 여러 파일을 동시에 선택할 수 없었음.
2. **첫 번째 파일만 처리**: `onchange` 핸들러에서 `target.files?.[0]`으로 첫 번째 파일만 가져와 처리하고 나머지 파일은 무시됨.

## 수정 내용

### 1. `addSingleImageToCanvas` 헬퍼 함수 추출

기존 `addImage` 내부의 단일 파일 처리 로직(업로드, AI/PSD 변환, 캔버스 추가)을 독립된 `addSingleImageToCanvas(file, canvas)` 함수로 분리.

**변경 전 (기존 코드)**:
```typescript
input.onchange = async (e: Event) => {
  const target = e.target as HTMLInputElement;
  const file = target.files?.[0]; // 첫 번째 파일만 처리
  if (!file) return;
  // ... 단일 파일 업로드/변환/캔버스 추가 로직 전체가 여기에 인라인
};
```

**변경 후**:
```typescript
const addSingleImageToCanvas = async (file: File, canvas: fabric.Canvas) => {
  // 단일 파일에 대한 업로드/변환/캔버스 추가 로직
  // - AI/PSD 파일: 변환 → 원본 업로드 → PNG 업로드 → 캔버스 추가
  // - 일반 이미지: 업로드 → 캔버스 추가
};
```

### 2. `addImage` 함수에 다중 파일 지원 추가

**변경 전**:
```typescript
const input = document.createElement('input');
input.type = 'file';
input.accept = 'image/*,.ai,.psd';
// multiple 속성 없음
```

**변경 후**:
```typescript
const input = document.createElement('input');
input.type = 'file';
input.accept = 'image/*,.ai,.psd';
input.multiple = true; // 다중 파일 선택 가능
```

### 3. `onchange` 핸들러 - 모든 파일 순차 처리

**변경 전**:
```typescript
const file = target.files?.[0]; // 첫 번째 파일만
```

**변경 후**:
```typescript
const files = target.files;
if (!files || files.length === 0) return;

const fileList = Array.from(files);
for (let i = 0; i < fileList.length; i++) {
  await addSingleImageToCanvas(fileList[i], canvas);
}
```

### 4. 진행 상태 표시 개선

여러 파일 업로드 시 로딩 모달에 현재 진행 상태를 표시:
- `(1/5) image1.png 처리 중...` 형식으로 진행 상황 표시
- 완료 시 `N개 파일이 추가되었습니다.` 메시지 표시
- 실패한 파일이 있어도 나머지 파일은 계속 처리

## 영향 범위

- **에디터 캔버스의 이미지 추가 기능**: 이제 파일 선택 다이얼로그에서 여러 파일을 동시에 선택 가능
- **기존 단일 파일 업로드**: 동작 변경 없음 (하위 호환)
- **AI/PSD 파일 변환**: 여러 AI/PSD 파일 동시 선택 시에도 각각 순차적으로 변환/업로드 처리
