# 2026-03-26 주요 수정 내용 요약

## 수정 1: 에디터 디자인 사양 썸네일 미표시 수정

### 증상
- 관리자 에디터 "디자인 사양" 섹션에서 객체 썸네일이 표시되지 않거나, 4면 중 일부만 표시되는 현상

### 원인
1. `SingleSideCanvas.tsx`에서 `enlivenObjects()` 완료 후 `canvasVersion`이 증가하지 않아 `objectPreviews` memo가 재계산되지 않음
2. 4면의 캔버스가 병렬 로드되면서 `toDataURL()` 호출 시점에 이미지가 완전히 decode되지 않아 실패 → fallback 부재

### 수정 내용
- **`components/canvas/SingleSideCanvas.tsx`**: `applyObjects()` 완료 후 `requestAnimationFrame` 내에서 `incrementCanvasVersion()` 호출 추가
- **`components/editor/panels/OrderModePanel.tsx`**: `canvas_state` JSON에서 이미지 원본 URL을 추출하는 `staticImagePreviews` memo 추가. `objectPreviews`에 해당 objectId가 없을 때 fallback으로 사용

## 수정 2: 에디터 목업 색상 필터 불일치 수정

### 증상
- 컬러칩을 흰색 선택 → 목업에 흰색 필터 확인 → 저장 후 새로고침하면 목업에 검정색 필터가 적용됨
- 공장 회원 / 어드민 계정 무관하게 동일 발생

### 원인
1. **`useEditorData.ts`**: 주문 모드에서 `canvas_state`의 `productColor`가 `#FFFFFF`이면 "미설정"으로 간주하여 `item_options.variants[0].color_hex`(블랙)로 덮어쓰는 로직
2. **`SingleSideCanvas.tsx`**: 메인 useEffect가 `canvasState`/`productColor`를 deps에서 제외하여, 클로저에 캡처된 값이 데이터 로드 전 기본값일 수 있고, 이후 `canvasState` 로드 시 색상 필터가 재적용되지 않음

### 수정 내용
- **`components/editor/hooks/useEditorData.ts`**: `extractedColor === '#FFFFFF'` 비교를 `foundInCanvasState` 불리언 플래그로 교체. `canvas_state`에 `productColor`가 존재하면 값에 관계없이 사용, 없는 경우에만 `item_options` 폴백
- **`components/canvas/SingleSideCanvas.tsx`**: `applyObjects()` 함수에서 오브젝트 로드 완료 후, 단일 이미지 모드(레이어 없음)일 때 `parsedState.productColor`로 배경 이미지 `BlendColor` 필터 재적용
